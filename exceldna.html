Excel-DNA 纯记事本开发极速指南 带参数提示功能

不用安装 Visual Studio，配合 Windows 记事本和命令行工具，开发具有和 Excel 内置公式一样完美参数悬浮提示的插件。

1. 环境准备 (只需一次)

  1. 下载并安装官方 .NET SDK (推荐 .NET 8.0 或更高版本)。
  2. 打开 Windows 命令提示符 (CMD)，运行以下命令安装 Excel-DNA 官方模板： 
    dotnet new install ExcelDna.Templates

2. 一键创建项目并添加参数提示包

在 CMD 中切换到您的工作目录（例如 D:\Projects），然后依次运行以下命令：

:: 1. 创建项目
dotnet new excel-dna -n MyAddIn

:: 2. 进入项目目录
cd MyAddIn

:: 3. 核心步骤：一键引入公式参数提示支持包
dotnet add package ExcelDna.IntelliSense

3. 记事本修改代码

  1. 在 MyAddIn 文件夹内，找到 AddIn.cs 文件，鼠标右键 -> 打开方式 -> 选择 记事本。
  2. 清空内容或直接修改，确保代码包含 IExcelAddIn 接口用以激活提示，并使用 [ExcelArgument] 来描述参数。完整模板如下： 
    using System;
using ExcelDna.Integration;
using ExcelDna.IntelliSense; // 引入提示命名空间

// 1. 必须实现此接口，用于在 Excel 启动时自动开启提示服务
public class MyAddInServer : IExcelAddIn
{
    public void AutoOpen()
    {
        IntelliSenseServer.Install(); // 激活参数提示服务
    }

    public void AutoClose()
    {
        IntelliSenseServer.Uninstall();
    }
}

// 2. 编写你的自定义公式
public static class MyFunctions
{
    [ExcelFunction(Description = "纯文本开发的简易加法，带参数提示")]
    public static double MyAdd(
        [ExcelArgument(Name = "数字A", Description = "需要相加 family 的第一个数字")] double a, 
        [ExcelArgument(Name = "数字B", Description = "需要相加的第二个数字")] double b)
    {
        return a + b;
    }
}
  3. 保存并关闭文件。

4. 命令行编译与测试

  1. 在 CMD 项目文件夹下执行编译： 
    dotnet build
  2. 编译成功后，打开输出路径：bin\Debug\net8.0-windows\
  3. 测试运行：
    • 如果您的 Excel 是 64 位，双击运行 MyAddIn-AddIn64.xll。
    • 如果您的 Excel 是 32 位，双击运行 MyAddIn-AddIn.xll。
  4. 在 Excel 单元格中输入 =MyAdd(，此时就会完美弹出**参数名称和描述的悬浮提示框**！

5. 独立单文件打包发布

当需要发给他人使用时，直接在 CMD 运行：

dotnet publish -c Release

去 bin\Release\net8.0-windows\publish\ 目录下找到带有 -packed.xll 后缀的文件。这个单文件已经将**参数提示组件、业务代码以及依赖项全部压缩打包在了一起**，发给谁都能直接双击使用并带有完整的提示功能！
